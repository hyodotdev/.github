## [OpenIAP](https://openiap.dev)

Unified in-app purchase infrastructure used across mobile and cross-platform apps.

OpenIAP provides a consistent API for handling in-app purchases across:

- iOS (StoreKit)
- Android (Google Play)
- React Native
- Expo
- Flutter
- Kotlin Multiplatform (KMP)
- Godot

## Why OpenIAP?

In-app purchases are critical infrastructure, but platform differences make them complex and difficult to maintain.

OpenIAP solves this by:

- Providing a unified API across platforms  
- Reducing integration overhead  
- Ensuring reliable, production-ready purchase flows
